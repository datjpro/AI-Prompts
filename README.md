## 🛠️ Công nghệ Sử dụng (Tech Stack)

Tất cả các dự án trong repository đều sử dụng bộ công nghệ Web hiện đại tiêu chuẩn:

* **Core Framework**: React 18 / Vite / TypeScript (hoặc JavaScript ES6+)
* **Styling**: Tailwind CSS / Vanilla CSS3 / CSS Modules / Glassmorphism Design Tokens
* **3D & Canvas Animations**: Three.js, React Three Fiber, HTML5 Canvas API
* **Motion & Micro-interactions**: Framer Motion, GSAP, CSS Keyframes
* **Iconography & Fonts**: Lucide React, Google Fonts (Geist, Special Elite, Inter, Outfit, Syne, Playfair Display)

## ⚡ Hướng dẫn Khởi chạy Dự án (Getting Started)

### 1. Yêu cầu Hệ thống (Prerequisites)
* Node.js LTS (Phiên bản `>= 18.0.0`)
* npm (Phiên bản `>= 9.0.0`) hoặc pnpm / yarn

### 2. Khởi chạy từng ứng dụng cụ thể
Mỗi thư mục dự án là một ứng dụng độc lập. Để chạy bất kỳ dự án nào:

```bash
# 1. Di chuyển vào thư mục dự án bạn muốn xem (Ví dụ: wandor-travel)
cd wandor-travel

# 2. Cài đặt các gói phụ thuộc (Dependencies)
npm install

# 3. Chạy môi trường phát triển (Development Server)
npm run dev
```

Sau khi chạy lệnh, truy cập địa chỉ được hiển thị ở terminal (thường là `http://localhost:5173`) trên trình duyệt để trải nghiệm ứng dụng.

## 💡 Bài học & Prompt Engineering Insights

Các file prompt `.txt` trong repository này áp dụng những nguyên tắc **Prompt Engineering** tiên tiến cho AI Development:
1. **Ranh giới Thiết kế Rõ ràng (Strict Design Tokens)**: Chỉ định rõ bộ màu HSL/HEX, Font Google chuẩn, Spacing và Breakpoints.
2. **Yêu cầu UI/UX Chi tiết (Component Specification)**: Định nghĩa chính xác cấu trúc HTML5 Semantic, thuộc tính ARIA và CSS Class.
3. **Không dùng Placeholder (Zero Dummy Content)**: Sử dụng các đường dẫn media thực tế hoặc canvas generator để tạo sản phẩm chạy thực tế 100%.
