# Velorah® — Glassmorphic Hero Section

A single-page hero section with a fullscreen looping background video, glassmorphic navigation, and cinematic typography for "Velorah®".

## 🌟 Features

- **Fullscreen Looping Background Video**: Clean object-cover video background with zero overlays or blobs.
- **Glassmorphic Navigation Bar**:
  - `Velorah®` logo in Instrument Serif display typography.
  - Desktop nav links (Home, Studio, About, Journal, Reach Us).
  - `.liquid-glass` pill CTA button ("Begin Journey").
- **Cinematic Typography & Contrast**:
  - `Instrument Serif` display font for the primary H1 heading: *"Where dreams rise through the silence."*
  - Color contrast highlighting on *"dreams"* and *"through the silence."* using muted HSL values.
  - `Inter` body font for subtext description.
- **Rise Animations**:
  - `animate-fade-rise`: H1 entrance animation.
  - `animate-fade-rise-delay`: Subtext entrance animation (0.2s delay).
  - `animate-fade-rise-delay-2`: Hero CTA button entrance animation (0.4s delay).
- **Liquid Glass System**: Custom `.liquid-glass` class with backdrop-blur and specular gradient mask border.

## 🛠️ Tech Stack

- **React 18** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **Google Fonts** (Instrument Serif & Inter)

## 🚀 Getting Started

```bash
# Navigate to project directory
cd velorah-hero

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
